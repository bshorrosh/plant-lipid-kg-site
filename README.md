# Plant Lipid Knowledge Graph

A literature-mined knowledge graph of plant acyl-lipid metabolism
(biosynthesis, degradation, trafficking and regulatory signaling) for
Arabidopsis, soybean and canola, built from published PubMed abstracts.
Every finding links to the paper it comes from. For Arabidopsis it builds on
the ARALIP curated gene set and pathway figures (*The Arabidopsis Book*,
[PMC3563272](https://pmc.ncbi.nlm.nih.gov/articles/PMC3563272/)), and new
papers are added every two weeks.

This repository hosts the website:
https://bshorrosh.github.io/plant-lipid-kg-site/

Everyone signs in with Google. Invited expert reviewers can also add notes
on the content, which feed into each update. For now the site is open only
to invited reviewers.

Privacy: https://bshorrosh.github.io/plant-lipid-kg-site/privacy.html
